安装 ​

环境准备 ​

Node.js 版本 ​

JustForFun-UI 需要 Node.js 版本 >= 18.0.0。

bash
# 检查 Node.js 版本
node -v
# 建议使用 v18.17.0 或更高版本

包管理器 ​

我们推荐使用 pnpm 以获得更好的性能和 monorepo 支持：

bash
# 安装 pnpm
npm install -g pnpm

# 检查 pnpm 版本
pnpm -v

镜像源配置 ​

为了在中国获得更快的包安装速度，你可以配置 npm/pnpm 镜像源。

使用 nrm（推荐） ​

bash
# 安装 nrm
npm install -g nrm

# 查看可用源
nrm ls
# * npm ------------ https://registry.npmjs.org/
# yarn ------------ https://registry.yarnpkg.com/
# tencent --------- https://mirrors.cloud.tencent.com/npm/
# cnpm ------------ https://r.cnpmjs.org/
# taobao ---------- https://registry.npmmirror.com/

切换到淘宝镜像 ​

bash
# 切换到淘宝镜像
nrm use taobao

# 验证
nrm ls
# taobao ---------- https://registry.npmmirror.com/ *

pnpm 配置 ​

bash
# 配置 pnpm 镜像
pnpm config set registry https://registry.npmmirror.com/

# 验证配置
pnpm config get registry
# https://registry.npmmirror.com/

依赖项 ​

JustForFun-UI 有以下 peer 依赖：

包版本必需
Vue>= 3.3.0✅
TypeScript>= 5.0.0可选
Vite>= 4.0.0推荐

安装检查 ​

安装后，验证所有设置是否正确：

bash
# 检查 Vue 版本
pnpm list vue

# 检查 TypeScript 版本（如果使用 TypeScript）
pnpm list typescript
