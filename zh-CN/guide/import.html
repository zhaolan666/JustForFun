按需导入 ​

JustForFun UI 支持多种按需导入方式，帮助你优化打包体积，实现更好的 Tree Shaking 效果。

方式一：自动按需导入（推荐） ​

使用 unplugin-vue-components 插件，实现组件的自动按需导入。

1. 安装插件 ​

bash
npm install -D unplugin-vue-components

2. 配置 Vite ​

typescript
// vite.config.ts
import { defineConfig } from 'vite'
import Components from 'unplugin-vue-components/vite'
import { JustForFunResolver } from 'justforfun-ui/resolver'

export default defineConfig({
  plugins: [
    Components({
      resolvers: [
        JustForFunResolver({
          importStyle: 'css', // 或 'scss', false
          prefix: 'Jff',
        }),
      ],
    }),
  ],
})

3. 使用组件 ​

vue
<template>
  <JffButton>按钮</JffButton>
  <JffInput v-model="text" />
</template>

<script setup lang="ts">
// 组件自动导入，无需手动 import！
const text = ref('')
</script>

方式二：手动按需导入 ​

从 components 导入 ​

typescript
// 命名导入
import { JffButton, JffInput, JffDialog } from 'justforfun-ui/components'

// 单个组件导入
import JffButton from 'justforfun-ui/components/button'
import JffInput from 'justforfun-ui/components/input'

导入样式 ​

typescript
// CSS 样式
import 'justforfun-ui/theme-chalk/button.css'
import 'justforfun-ui/theme-chalk/input.css'

// SCSS 源码（支持自定义主题变量）
import '@justforfun-ui/theme-chalk/src/button.scss'
import '@justforfun-ui/theme-chalk/src/input.scss'

完整示例 ​

vue
<template>
  <JffButton type="primary">主要按钮</JffButton>
  <JffInput v-model="text" placeholder="请输入内容" />
</template>

<script setup lang="ts">
import { ref } from 'vue'
import { JffButton, JffInput } from 'justforfun-ui/components'
import 'justforfun-ui/theme-chalk/button.css'
import 'justforfun-ui/theme-chalk/input.css'

const text = ref('')
</script>

方式三：使用样式加载器 ​

JustForFun UI 提供了样式加载器，支持异步加载组件样式。

typescript
import { loadButton, loadInput } from 'justforfun-ui/style-loader'

// 异步加载样式
loadButton()
loadInput()

方式四：完整导入 ​

如果你需要使用所有组件，可以选择完整导入：

typescript
// main.ts
import { createApp } from 'vue'
import App from './App.vue'
import JffUI from 'justforfun-ui'
import 'justforfun-ui/theme-chalk/index.css'

const app = createApp(App)
app.use(JffUI)
app.mount('#app')

Tree Shaking 效果 ​

使用按需导入后，打包体积可显著减少：

场景优化前优化后减少
完整导入~500KB~500KB-
按需导入 1 个组件~500KB~30KB94% ↓
按需导入 3 个组件~500KB~80KB84% ↓
按需导入 + 样式~500KB~120KB76% ↓

构建工具配置 ​

Webpack ​

javascript
// webpack.config.js
module.exports = {
  optimization: {
    usedExports: true,
    sideEffects: true,
  },
}

Rollup ​

javascript
// rollup.config.js
export default {
  treeshake: {
    moduleSideEffects: true,
  },
}

Vite ​

Vite 默认支持 Tree Shaking，无需额外配置。

自定义主题变量（SCSS） ​

使用 SCSS 可以自定义主题变量：

scss
// 自定义主题变量
@use '@justforfun-ui/theme-chalk/src/common/var.scss' with (
  $button-bg-color: #409EFF,
  $button-font-color: #fff
);

// 导入组件样式
@use '@justforfun-ui/theme-chalk/src/button.scss';

注意事项 ​

  1. 样式导入顺序：基础样式（如 button.scss）需要在依赖它的组件之前导入
  2. SCSS 变量覆盖：需要在导入组件样式之前进行变量覆盖
  3. TypeScript 类型：使用 dts: 'src/components.d.ts' 自动生成类型声明
  4. 生产环境：确保构建工具启用了 tree-shaking 和 sideEffects
